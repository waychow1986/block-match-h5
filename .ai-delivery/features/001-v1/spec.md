# 方块消除小游戏：计分与关卡 产品规格

> 依据：意图第 2 版（已在 G1 确认，含 Q1–Q4、R1–R5 的人工答案）与需求原文 `request.json`。本规格只写“做成什么样”，不做技术选择。
> 来源写法：“AC-n”指意图的验收标准；“范围 n”指意图范围第 n 条；“原文玩法 n / 原文精致 n”指需求原文“玩法”第 n 条、“精致的要求”第 n 项；“Q1–Q4、R1–R5”指意图中 G1 前后由人回答的问题（answeredBy：e2e-delegate）。
> 本次没有 `g2Decisions`；没有 `requirements/` 提炼结果。

## 产品目标与边界

做一个在电脑浏览器（鼠标）和手机浏览器（触摸）里都能玩的消除方块小游戏：玩家消除上下左右相连、同色、至少 2 个的一组方块得分，一次消得越多得分越高；游戏分关卡、不设关卡上限、越往后越难；界面显示当前分数、本关目标分数、当前关卡和本机历史最高分；有悬停/按住突出显示、连续过渡动画、过关与游戏结束提示画面、音效与一键静音，并在窗口大小变化和手机竖屏下自适应、不出现横向滚动。（来源：意图“要解决的问题”、范围 1–8）

不做的内容见文末“范围外边界”。

## 参与者与权限

- **玩家**：打开页面即可游玩，不需要登录或注册；没有其他角色。（来源：范围 1；不做的事“账号登录”“后台管理”）
- 玩家能看到和改变的数据只有本机浏览器中的游戏状态与历史最高分。（来源：范围 5；不做的事“跨设备或云端同步最高分”）

## 领域术语

| 术语 | 含义 |
|---|---|
| 方块 | 棋盘上一个格子中的有色单元，每个方块有一种颜色。 |
| 相连 | 两个方块在同一行左右相邻或同一列上下相邻；斜向不算相连。 |
| 组 | 从某个方块出发，经同色相连关系能到达的全部方块（含自身）的集合。 |
| 可消除组 | 方块数不少于 2 的组。 |
| 单个方块 | 所在组只有它自己的方块（上下左右都没有同色方块）。 |
| 当前分数 | 本局从第 1 关开始累计得到的总分，关卡之间不清零。（来源：Q1） |
| 本关目标分数 | 本关的过关门槛，是一个累计总分门槛。（来源：Q1） |
| 本关需新得分数 | 本关目标分数减去上一关目标分数；第 1 关为第 1 关目标分数本身。（来源：R3） |
| 一局 | 从第 1 关、分数 0 开始，到游戏结束为止的一次游戏过程。（来源：Q2） |
| 历史最高分 | 本机本浏览器中曾经达到过的最高当前分数。（来源：范围 5、R1、意图假设） |
| 本关结束 | 棋盘上不再有任何可消除组的时刻。（来源：AC-7） |

## 用户故事

### US-1 消除方块得分（P1）
作为玩家，我希望点击（手机上轻点）一组相连的同色方块就能把它们消除并得分，以便推进本关。（来源：范围 1–3；AC-1–AC-5）

### US-2 闯关（P1）
作为玩家，我希望每关有目标分数，达到就进入更难的下一关，未达到就游戏结束并能重新开始，以便有持续的挑战。（来源：范围 4；AC-7–AC-9；Q1–Q3；R3）

### US-3 了解进度与纪录（P1）
作为玩家，我希望随时看到当前分数、本关目标分数、当前关卡和本机历史最高分，并且下次打开还能看到历史最高分，以便知道离目标和纪录还差多少。（来源：范围 5；AC-6、AC-10；R1）

### US-4 精致的观感与反馈（P2）
作为玩家，我希望在消除前能看出将消除哪一组，消除、下落、靠拢、加分有连续动画，过关与游戏结束有明显提示画面，并有可一键静音的音效，以便玩得清楚、舒服。（来源：范围 6–7；AC-11–AC-14；R2、R5）

### US-5 在不同屏幕上游玩（P1）
作为玩家，我希望在电脑上改变窗口大小或在手机竖屏下，棋盘都能完整显示、页面不横向滚动，以便在任何设备上都能直接玩。（来源：范围 1、8；AC-1、AC-15）

## 功能需求

### 输入与可玩性

- **FR-001**：游戏在电脑浏览器中可用鼠标完成全部游戏操作，在手机浏览器中可用触摸完成全部游戏操作；打开页面后无需登录即可开始游玩，并能一直玩到本关结束（消除、得分、本关结束判定都可发生）。（来源：AC-1；范围 1；不做的事“账号登录”）
- **FR-002**：在电脑上，对一个方块单击（按下并在同一方块上松开）即对该方块所在的组执行“消除尝试”；在手机上，一次轻点即执行消除尝试，不需要先选中再确认。（来源：AC-2；原文玩法 1；意图假设“手机上轻点即消除”）

### 棋盘与消除

- **FR-003**：每关开始时，棋盘的每个格子都放着一个方块，方块的颜色从本关的颜色种类中取得；同一棋盘上至少出现 2 种颜色。（来源：AC-2；范围 2；原文玩法 1）
- **FR-004**：对可消除组执行消除尝试时，该组的全部方块被消除；该组以外的方块一个都不被消除（包括与该组同色、但不与该组相连的方块）。（来源：AC-2）
- **FR-005**：对单个方块执行消除尝试时，不消除任何方块，棋盘不变，当前分数不变。（来源：AC-3）
- **FR-006**：对空格子（没有方块的位置）执行操作时，不发生任何变化。（来源：AC-2、AC-3 的边界；见假设 A-3）
- **FR-007**：消除后，每一列中位于被消除位置上方的方块向下移动，直到该列所有方块从底部起连续排列、方块之间不留空格；方块在下落中不改变颜色、不改变所在列。（来源：AC-4；原文玩法 1）
- **FR-008**：下落完成后，若某一列中已没有任何方块，该列右侧的所有列整体向左移动，直到所有非空列从最左侧起连续排列、非空列之间不留空列；列在靠拢中保持原有的上下顺序和颜色。（来源：AC-4；原文玩法 1）

### 计分

- **FR-009**：每次成功消除获得的分数只取决于这次消除的方块数 n（n ≥ 2），记为 S(n)，且 S(n) > 0。（来源：AC-5；范围 3）
- **FR-010**：S(n) 随 n 严格递增：一次消除的方块数越多，这次得分越高。（来源：AC-5；原文玩法 2）
- **FR-011**：对任意 N ≥ 2，一次消除 2N 个方块的得分不低于分两次各消除 N 个方块得分之和的 2 倍，即 S(2N) ≥ 2 × (S(N) + S(N))。（来源：AC-5；Q4 答案）
- **FR-012**：把 n 个方块拆成任意两组或更多组（每组至少 2 个）分开消除时，一次消除 n 个方块的得分严格高于各组得分之和。（来源：AC-5；Q4 答案）
- **FR-013**：每次成功消除后，这次得分立即计入当前分数；对单个方块或空格子的操作不改变当前分数。（来源：AC-3、AC-6）

### 界面信息

- **FR-014**：游戏进行中，界面始终同时显示当前分数、本关目标分数、当前关卡（关卡序号，从 1 开始）和历史最高分；这些信息在棋盘动画、过关提示画面、游戏结束提示画面出现时也不被移除。（来源：AC-6；范围 5）
- **FR-015**：每次成功消除后，界面显示的当前分数更新为加上这次得分后的值；进入下一关后，本关目标分数和当前关卡更新为新一关的值。（来源：AC-6）

### 关卡与结束判定

- **FR-016**：每次消除及其下落、靠拢完成后，若棋盘上不再有任何可消除组（包括棋盘已被清空的情况），本关结束；只要还有可消除组，本关就不结束（即使当前分数已经达到本关目标分数）。（来源：AC-7；原文玩法 3）
- **FR-017**：本关结束时，若当前分数大于或等于本关目标分数，判定为过关，进入下一关；否则判定为游戏结束。（来源：AC-7；Q1 答案）
- **FR-018**：进入下一关时，当前分数保持不变（不清零），关卡序号加 1，棋盘换成按新一关颜色种类生成的新棋盘（满足 FR-003）。（来源：AC-7；Q1 答案）
- **FR-019**：关卡数量不设上限；不存在“全部通关”的结局，游戏只会以游戏结束告终。（来源：Q3 答案）
- **FR-020**：相邻两关之间：后一关的颜色种类不少于前一关；后一关的本关目标分数严格高于前一关；后一关的本关需新得分数不低于前一关的本关需新得分数。（来源：AC-9；R3 答案；原文玩法 3）
- **FR-021**：颜色种类随关卡增加到一个上限后不再增加，此后的关卡只靠提高目标分数增加难度，并仍满足 FR-020。（来源：Q3 答案；AC-9）

### 重新开始与进度

- **FR-022**：游戏结束后，界面上提供一个“重新开始”操作；玩家执行后，新的一局从第 1 关开始，当前分数为 0，棋盘为第 1 关的新棋盘，历史最高分保持不变。（来源：AC-8；Q2 答案）
- **FR-023**：游戏进行中刷新或关闭页面后再打开，不恢复进行中的关卡、分数和棋盘，而是从第 1 关、分数 0 开始新的一局；只保留历史最高分。（来源：R4 答案）

### 历史最高分

- **FR-024**：当前分数一旦超过已保存的历史最高分，历史最高分立即更新为当前分数并保存在本机浏览器中，无论这一局是否已经结束；此后在同一设备同一浏览器中关闭并重新打开页面，界面显示的历史最高分等于该值。（来源：AC-10；R1 答案；范围 5）
- **FR-025**：本机浏览器中从未保存过历史最高分时，历史最高分显示为 0。（来源：范围 5；见假设 A-6）
- **FR-026**：历史最高分只保存在本机浏览器中，不需要账号，也不在设备或浏览器之间同步；清除浏览器数据后历史最高分可能回到初始状态。（来源：范围 5；意图假设；不做的事“跨设备或云端同步最高分”）

### 突出显示

- **FR-027**：电脑上，鼠标指针停在某个可消除组的任一方块上时，该组全部方块以与其他方块明显不同的样式显示；指针移出该组后恢复原样式。（来源：AC-11；范围 6；原文精致 1）
- **FR-028**：鼠标按下或手机上手指按住某个可消除组的任一方块期间，该组全部方块以与其他方块明显不同的样式显示；松开或手指离开后恢复。（来源：AC-11；意图假设“手机上按手指按住期间突出显示该组”）
- **FR-029**：指针停在、按下或按住单个方块时，不出现可消除组的突出显示样式。（来源：AC-11、AC-3；见假设 A-4）

### 动画

- **FR-030**：被消除的方块以连续的过渡动画离开棋盘，而不是瞬间消失。（来源：AC-12；范围 6）
- **FR-031**：下落补位的方块以连续的移动动画从原位置移动到新位置，而不是瞬间出现在新位置。（来源：AC-12）
- **FR-032**：向左靠拢的列以连续的移动动画从原位置移动到新位置。（来源：AC-12）
- **FR-033**：每次成功消除得分时，有表现这次得分的连续过渡动画（界面上可以看到这次所得分数，或当前分数以连续变化的方式增加到新值）。（来源：AC-12；原文精致 2“加分都有流畅的动画”）

### 提示画面

- **FR-034**：过关时，出现一个覆盖在棋盘之上的提示画面，写明“过关”；游戏结束时，出现一个覆盖在棋盘之上的提示画面，写明“游戏结束”。两种画面文字不同，能区分。（来源：AC-13；范围 6）
- **FR-035**：过关提示画面中提供一个进入下一关的操作，玩家执行后提示画面消失、显示下一关的新棋盘；游戏结束提示画面中提供 FR-022 的“重新开始”操作。提示画面显示期间，棋盘上的方块不响应消除操作。（来源：AC-13、AC-8、AC-7；见假设 A-7）

### 音效与静音

- **FR-036**：成功消除方块时、过关时、游戏结束时各播放一次音效。（来源：AC-14；R2 答案；范围 7）
- **FR-037**：界面上始终有一个静音按钮；点一次后，此后所有音效都不再播放（包括正在播放的音效立即停止）；再点一次后恢复播放音效。（来源：AC-14；范围 7；按钮状态的显示见假设 A-8）
- **FR-038**：静音状态在本次打开页面期间一直有效，包括跨关卡和重新开始之后。（来源：意图假设“静音状态至少在本次打开页面期间保持有效”）

### 自适应布局

- **FR-039**：改变电脑浏览器窗口大小时，棋盘随可视区域缩放，整个棋盘（所有行和列）完整显示在可视区域宽度之内；页面不出现横向滚动条，也不能横向滚动。（来源：AC-15；范围 8）
- **FR-040**：在手机竖屏下，棋盘随屏幕宽度缩放，整个棋盘完整显示，页面不出现横向滚动条，也不能横向滚动；分数、目标分数、关卡、历史最高分和静音按钮同样可见、可操作。（来源：AC-15、AC-6、AC-14；范围 8）

### 观感

- **FR-041**：不同颜色的方块之间能清楚区分，方块呈现立体感；这一项由业务负责人在验收时目视确认。（来源：R5 答案；范围 6；原文精致 1）

## 产品质量要求

当前没有获批准的额外质量要求（没有帧率、加载时限、可用率等数值指标）。与观感有关的要求只有：动画以 FR-030–FR-033 的“连续过渡、不是瞬间跳到结果”判定（来源：AC-12；意图假设“不另设帧率指标”）；配色与立体感按 FR-041 由业务负责人目视确认（来源：R5）。

## 前置条件与触发条件

- **前置条件**：玩家使用意图假设所列的主流浏览器（电脑：Chrome、Edge、Firefox、Safari；手机：iOS Safari、Android Chrome）打开游戏页面。（来源：意图假设）
- **触发条件**：
  - 打开页面 → 开始新的一局（第 1 关、分数 0），显示本机历史最高分。（FR-023、FR-025）
  - 单击/轻点方块 → 消除尝试。（FR-002）
  - 悬停/按下/按住方块 → 突出显示。（FR-027、FR-028）
  - 本关结束 → 过关或游戏结束。（FR-016、FR-017）
  - 点击提示画面上的操作 → 进入下一关或重新开始。（FR-022、FR-035）
  - 点击静音按钮 → 切换静音。（FR-037）
  - 窗口大小或屏幕方向变化 → 棋盘重新适配。（FR-039、FR-040）

## 行为模型

### US-1 消除方块得分

- **正常**：玩家悬停（电脑）或按住（手机）某个可消除组 → 该组突出显示（FR-027、FR-028）→ 单击/轻点 → 该组全部消除，有消除动画与音效（FR-004、FR-030、FR-036）→ 上方方块下落、空列右侧的列左移，均有动画（FR-007、FR-008、FR-031、FR-032）→ 得分按 S(n) 计入当前分数，有加分动画，界面分数更新（FR-009–FR-013、FR-015、FR-033）。
- **边界**：同色但不相连的方块不受影响（FR-004）；斜向相邻不算相连（领域术语）；消除使最左列或中间某列变空时，右侧各列左移（FR-008）；最右列变空时没有需要左移的列。
- **无效操作**：单击/轻点单个方块或空格子 → 不消除、分数不变、不突出显示（FR-005、FR-006、FR-029）。
- **动画进行中**：上一次消除的动画未完成时，新的操作按假设 A-2 处理。

### US-2 闯关

- **正常（过关）**：最后一次消除完成后棋盘上没有可消除组，且当前分数 ≥ 本关目标分数 → 播放过关音效，出现“过关”提示画面（FR-016、FR-017、FR-034、FR-036）→ 玩家执行进入下一关操作 → 关卡 +1、分数保持、新棋盘、新目标分数（FR-018、FR-035）。
- **正常（游戏结束）**：本关结束且当前分数 < 本关目标分数 → 播放游戏结束音效，出现“游戏结束”提示画面（FR-017、FR-034、FR-036）→ 玩家执行“重新开始” → 第 1 关、分数 0、新棋盘，历史最高分不变（FR-022）。
- **边界**：当前分数恰好等于本关目标分数算过关（FR-017）；分数早已达到目标但棋盘仍有可消除组时继续本关（FR-016）；棋盘被全部消除空时本关结束，不另加分（FR-016；范围外“剩余方块奖励”）；颜色种类到上限后只有目标分数继续提高（FR-021）；没有最后一关（FR-019）。
- **难度**：任意相邻两关满足 FR-020。

### US-3 了解进度与纪录

- **正常**：界面一直显示当前分数、本关目标分数、当前关卡、历史最高分（FR-014）；消除后分数更新（FR-015）。
- **新纪录**：当前分数超过历史最高分时，历史最高分随即更新并保存（FR-024；显示方式见假设 A-5）。
- **恢复**：中途关闭或刷新页面后重新打开 → 新的一局从第 1 关开始，历史最高分保留为关闭前已保存的值（FR-023、FR-024）。
- **首次打开**：历史最高分显示 0（FR-025）。

### US-4 精致的观感与反馈

- **正常**：悬停/按住可消除组 → 突出显示；消除、下落、靠拢、加分均为连续动画；过关、游戏结束有覆盖棋盘的提示画面；消除、过关、游戏结束有音效（FR-027–FR-036）。
- **静音**：点静音按钮 → 所有音效停止且之后不再播放；再点 → 恢复；本次打开页面期间保持（FR-037、FR-038）。
- **手机手指移动**：手指按住后移出原方块再松开，按假设 A-4 处理。

### US-5 在不同屏幕上游玩

- **正常**：电脑窗口变宽/变窄、手机竖屏 → 棋盘缩放并完整显示，界面信息与静音按钮可见可用，页面无横向滚动（FR-039、FR-040）。
- **边界**：窗口在游戏进行中改变大小时，棋盘状态、分数、关卡不变，只改变显示尺寸（见假设 A-9）。

## 业务状态、业务数据规则与不变量

- **游戏状态**：进行中 → （本关结束）→ 过关提示 → 进行中（下一关）；进行中 → （本关结束）→ 游戏结束提示 → 进行中（第 1 关，新的一局）。没有其他终态。（来源：FR-016–FR-022、FR-035）
- **不变量**：
  - 进行中，每一列的方块从底部起连续排列；所有非空列从最左侧起连续排列。（FR-007、FR-008）
  - 当前分数在一局内只增不减；只在新的一局开始时变为 0。（FR-013、FR-018、FR-022、FR-023）
  - 历史最高分 ≥ 本次打开页面以来任一时刻的当前分数，并且只增不减（清除浏览器数据除外）。（FR-024、FR-026）
  - 相邻两关满足 FR-020。
- **本机保存的数据**：只有历史最高分（一个数值）。进行中的关卡、分数、棋盘不保存（FR-023、FR-026）。静音状态是否跨次打开保存不作承诺（意图假设）。

## 错误与恢复行为

- 无效点击（单个方块、空格子）：不产生任何变化，不是错误，不提示。（FR-005、FR-006）
- 本机无法读取或保存历史最高分时（例如浏览器禁止本机保存）：游戏仍可正常进行，历史最高分按本次打开页面期间的值显示。（补充 FR-024、FR-025；见假设 A-10）
- 中途关闭、刷新页面：按 FR-023 开始新的一局。

## 安全、隐私与可访问性行为

- 不需要账号，不收集玩家个人信息；本机只保存历史最高分。（来源：不做的事“账号登录”；范围 5；FR-026）
- 当前没有其他获批准的安全、隐私或可访问性要求。

当前没有获批准的额外要求。

## 验收标准

沿用意图的验收标准编号。AC-9、AC-10、AC-14 按 G1 中人的答案（R3、R1、R2）修订后的文字为准；AC-16 是按 R5 答案补充的一条，由业务负责人目视确认。

- **AC-1**：在电脑浏览器中用鼠标、在手机浏览器中用触摸，都能从打开页面开始玩到本关结束（消除方块、得分、本关结束判定）。
- **AC-2**：棋盘由多种颜色的方块组成；点击（手机上轻点）一组上下左右相连、颜色相同、数量至少 2 个的方块时，这一组全部方块被消除，且只消除这一组。
- **AC-3**：点击（轻点）一个没有上下左右同色相邻方块的单个方块时，不发生消除，分数不变。
- **AC-4**：消除后，被消除位置上方的方块下落补位，同一列中方块之间不留空位；某一整列变空时，其右侧的各列向左靠拢，列与列之间不留空列。
- **AC-5**：一次消除的方块数越多，这次得分越高；一次消除 2N 个方块的得分至少是分两次各消除 N 个方块得分之和的 2 倍；对其他任意拆法（每组至少 2 个），一次消除的得分严格高于分开消除的得分之和。（按 Q4 答案写明分界）
- **AC-6**：界面始终显示当前分数、本关目标分数和当前关卡；每次消除后显示的分数随之更新。
- **AC-7**：棋盘上不再有任何可以消除的一组时，本关结束；结束时分数达到本关目标分数则进入下一关，未达到则游戏结束。
- **AC-8**：游戏结束后，玩家可以通过界面上的操作重新开始游戏。
- **AC-9**（按 R3 修订）：后一关的颜色种类多于前一关，或目标分数高于前一关（至少其一，另一项不降低）；并且后一关的本关需新得分数（本关目标减上一关目标）不低于前一关。
- **AC-10**（按 R1 修订）：当前分数超过原最高分后（无论这一局是否已经结束），关闭并重新打开页面（同一设备同一浏览器），界面仍显示该最高分。
- **AC-11**：电脑上鼠标悬停在一组可消除方块上、或按下（手机上手指按住）时，这一组的全部方块以区别于其他方块的样式突出显示。
- **AC-12**：方块的消除、下落、列靠拢和加分都以连续的过渡动画呈现，而不是瞬间跳到结果状态。
- **AC-13**：过关时和游戏结束时，各出现一个覆盖在棋盘之上的提示画面，分别写明过关或游戏结束。
- **AC-14**（按 R2 修订）：消除方块、过关、游戏结束时各播放音效；界面上有一个静音按钮，点一次即停止所有音效，再点一次恢复。
- **AC-15**：改变电脑浏览器窗口大小以及在手机竖屏下，棋盘随可视区域缩放并完整显示，页面不出现横向滚动条，也不能横向滚动。
- **AC-16**（按 R5 补充）：方块配色清楚、不同颜色之间易于区分，方块有立体感；由业务负责人在验收时目视确认。

## 假设、依赖与范围外边界

### 假设（随规格在 G2 交业务负责人查看，可以修改）

- **A-1**（补充 FR-003、FR-020、FR-021）：棋盘行列数、每关的具体颜色种类数、颜色上限、各关目标分数的具体数值、计分函数 S(n) 的具体形式、配色和音效素材由设计决定，只要满足所引用的功能需求；各关棋盘尺寸相同。
- **A-2**（补充 FR-002、FR-004）：上一次消除的消除、下落、靠拢动画尚未完成时，棋盘上的消除操作不生效（不排队、不消除），动画完成后才能进行下一次消除。
- **A-3**（补充 FR-006）：点击或轻点棋盘上的空格子不发生任何变化，也不突出显示。
- **A-4**（补充 FR-002、FR-028、FR-029）：手机上手指按住一个方块后，若手指移到其他方块或棋盘外再松开，不执行消除；单个方块被悬停、按下或按住时不突出显示。
- **A-5**（补充 FR-014、FR-024）：当前分数超过历史最高分后，界面上显示的历史最高分随之同步变为当前分数；不另外弹出“新纪录”提示。
- **A-6**（补充 FR-025）：本机没有保存过历史最高分时显示 0。
- **A-7**（补充 FR-035）：过关提示画面不会自动消失，玩家执行提示画面上的“下一关”操作后才进入下一关；过关与游戏结束提示画面中同时显示当前分数。
- **A-8**（补充 FR-037）：静音按钮的外观（图标或文字）随静音/有声状态变化，能看出当前状态。
- **A-9**（补充 FR-039、FR-040）：游戏进行中改变窗口大小或屏幕方向，只改变显示尺寸，不改变棋盘内容、分数、关卡，也不中断游戏；AC-15 对手机只要求竖屏，手机横屏的显示不作承诺。
- **A-10**（补充 FR-024、FR-025）：浏览器不允许在本机保存数据时，游戏仍可正常游玩，历史最高分只在本次打开页面期间有效，不提示错误。
- **A-11**（补充 FR-036）：浏览器要求玩家先与页面交互后才允许播放声音；音效在玩家第一次点击或轻点之后才开始可用。
- **A-12**（补充 FR-020）：第 1 关的“上一关目标分数”按 0 计，第 1 关的本关需新得分数即第 1 关目标分数。
